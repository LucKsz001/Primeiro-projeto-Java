## 📌 Sobre o projeto

Este repositório marca o início da minha jornada com a linguagem **Java**. O programa consiste em uma aplicação simples de console que exibe uma mensagem de boas-vindas, servindo como base para praticar:

- Estrutura básica de uma classe Java;
- O método `main` (ponto de entrada da aplicação);
- Saída de dados com `System.out.println`;
- Compilação e execução de código Java.

---

## ✨ Funcionalidade

- Exibe a mensagem **"Bem vindos! ao meu projeto em Java"** no terminal.

## 🛠️ Tecnologias utilizadas

- **Java** (JDK 8 ou superior)
- **Visual Studio Code** (com extensão Java, conforme pasta `.vscode`)

---

## 📋 Pré-requisitos

- **Java Development Kit (JDK)** instalado.
- (Opcional) **VS Code** com o pacote de extensões Java da Microsoft.

> Para verificar se o Java está instalado, execute no terminal:
> ```bash
> java -version
> ```

## 🚀 Como executar

### Opção 1 — Pelo terminal (manual)

```bash
# 1. Clone o repositório
git clone https://github.com/LucKsz001/Primeiro-projeto-Java.git

# 2. Entre na pasta
cd Primeiro-projeto-Java

# 3. Compile o código (a partir da raiz)
javac src/App.java -d bin

# 4. Execute
java -cp bin App
```

### Opção 2 — Pelo VS Code

1. Abra a pasta do projeto no VS Code.
2. Abra o arquivo `src/App.java`.
3. Clique no botão **Run** (▶️) no canto superior direito ou pressione `F5`.

### Opção 3 — Usando a pasta `bin` (se já estiver compilado)

```bash
java -cp bin App
```

## 📚 O que aprendi

- Criar e compilar um arquivo `.java`;
- Entender a estrutura `public class App { public static void main(String[] args) { ... } }`;
- Utilizar `System.out.println` para exibir textos no console;
- Organizar pastas de um projeto Java (`src` para código, `bin` para compilados).
